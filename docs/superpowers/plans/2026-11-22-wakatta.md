# Wakatta? (わかった？) — Implementation Plan

> Steps use checkbox (`- [ ]`) syntax for tracking. Owners are picked during the build; write your name next to a workstream when you take it. Terms in **bold** are defined in [GLOSSARY.md](../../../GLOSSARY.md); use them in code, UI copy and the proposal.

**Goal:** Understood at work. Understood at home. A foreman's 20-second voice note becomes a やさしい日本語, Bengali and English instruction pinned to the machine, and Wakatta? proves the worker understood before the first cut. The same worker's neighbourhood notices (a photo of a garbage flyer, a drill, a festival) become plain steps with dates in their calendar, and a Japanese **Senpai** links them to the street they live on.

**Two tabs, one pipeline:** *Work* (Machines, Checks, Sign-offs, Briefings, Near-miss Reports) and *Life* (**Notices**, **Events**, **Asks**, Senpai, **Meet-ups**). Both use the same Japanese-in → plain steps + Check out pipeline ([ADR 0004](../../adr/0004-one-app-work-and-life.md)).

**Why the employer owns Life too:** for 特定技能1号 workers, the employer or its 登録支援機関 must by law provide life orientation, consultation and support for exchange with Japanese people (義務的支援; verify item wording in the 出入国在留管理庁 運用要領, 令和8年8月版). The **Support Log** turns Wakatta? data into evidence of that support. Degree-level engineers (技人国) are not covered by this duty; for them Life is retention, not compliance.

**Problem (proposal wording, keep exact):** In MHLW's 2025 外国人雇用実態調査, 46.2% of employers name 「日本語能力等のためにコミュニケーションが取りにくい」 as a challenge, the most-cited one (up from 43.9%) ([MHLW, published 2026-08-31](https://www.mhlw.go.jp/stf/newpage_75722.html)). Injury rates per 1,000: 3.98 (技能実習), 3.91 (特定技能), 2.3 (all workers). These are shop-floor figures; do not mix them with Nagasaki's degree-level engineer programme (3 confirmed hires). Pitch angle for that programme: those engineers become the bilingual **Foremen** who run this system.

**Only feature no competitor has** (checked 2026-11-22 against 22 products, [competitors.md](../../../contributors/asif/founder/competitors.md)): the **Check** gates a specific **Machine** through its **Machine Panel**, and every **Confusion** alerts the **Foreman** with the exact **Glossary Term**; no product we found does either, or writes it into the record a 登録支援機関 must keep. What others already do, so never claim it as ours: カミナシ translates manuals and runs tests in 18 languages and supports Bengali; Teachme Biz runs tests and opens manuals from on-site QR codes; tebiki translates video manuals (no test feature found). Fastest copier: カミナシ. Every screen should serve this story.

**Architecture:** TanStack Start frontend (existing `frontend/` scaffold) → FastAPI backend (`backend/app/`, routers → services) → Postgres. Gemini does all AI steps ([ADR 0001](../../adr/0001-gemini-for-all-ai-steps.md)). Hosted on Azure Container Apps + PostgreSQL Flexible Server ([ADR 0002](../../adr/0002-fastapi-postgres-on-azure.md)). The Lock is software only ([ADR 0003](../../adr/0003-software-lock-not-hardware-interlock.md)). Backend design (tables, rules, API decisions, AI pipeline, security, deploy): [docs/BACKEND_ARCHITECTURE.md](../../BACKEND_ARCHITECTURE.md), ADRs 0005–0008.

**Tech stack:** Frontend per [docs/FRONTEND_STACK.md](../../FRONTEND_STACK.md) (React 19, TanStack Router/Query/Form, Zod, Tailwind 4, shadcn in `src/ui/v1/`, Paraglide ja/en/bn). Backend: Python 3.12, FastAPI, SQLModel, Alembic, psycopg 3, `google-genai` SDK, pytest. QR: `qrcode` npm package for printing stickers; scanning is the phone camera opening the URL (no in-app scanner).

## Global constraints

- **Demo never breaks (F-42, AGENTS.md §4.3).** Every Gemini call has a fallback: seeded Note Versions for the 4 demo Machines, and a cache keyed by audio hash so the filmed take replays instantly. `USE_MOCK` in `frontend/src/services/api.ts` must run every demo journey with no backend.
- **Everyone has their own account.** Workers and Foremen pick their name from their shop's roster and type a personal PIN (4 digits for Workers, 6 for Foremen); **Community Posters** sign in the same way to their district and can only post Notices and see their reach, never shop data. Login returns a Bearer token; a Worker's phone stays signed in for 30 days. Foremen create and reset Worker accounts. A Senpai opens `/senpai/$token`; a Machine Panel uses a device token. Many shops share one system; each shop sees only its own data. Details: [BACKEND_ARCHITECTURE.md §2–3](../../BACKEND_ARCHITECTURE.md#2-scopes-and-tenancy), [ADR 0009](../../adr/0009-shop-and-district-scopes.md), [ADR 0010](../../adr/0010-personal-accounts-and-pins.md).
- **Asks never invent rules.** Answers come only from published Notices + Glossary, quote the source Notice, and otherwise say 「掲示された案内にはありません」 and offer one tap to forward the Ask (translated to Japanese) to the Worker's Senpai.
- **Dates are checked in code.** Gemini proposes Events as RRULE strings; the backend parses them with `python-dateutil`, shows the next 3 dates to the poster, and publishes only after the poster confirms. Times are `Asia/Tokyo`.
- **Languages.** Content: やさしい日本語 (source of truth), Bengali, English. UI: ja / en / bn via Paraglide. Worker toggles BN/EN for Checks; Japanese is always one tap away.
- **Glossary lock.** A **Glossary Term**'s translations are fixed. The AI output is validated: every glossary term present in the Japanese text must appear with its fixed translation in BN and EN, or the output is rejected and retried once, then marked for Foreman edit. Exact rule: [BACKEND_ARCHITECTURE.md §7.4](../../BACKEND_ARCHITECTURE.md#74-glossary-lock-with-galibs-review-point-4).
- **Sign-off validity.** Valid when it matches the Machine's current approved Note Version AND is under 90 days old. "Expiring" = under 14 days left. A newly approved **Safety Change** invalidates every older Sign-off for that Machine; a **Wording Change** does not. A Foreman can grant a named, time-limited **Panel Override** so the lock never silently stops production ([BACKEND_ARCHITECTURE.md §7.1](../../BACKEND_ARCHITECTURE.md#71-sign-off-and-lock)).
- **Envelope.** Every response uses the envelope in [docs/API_SPEC.md §1](../../API_SPEC.md). `docs/openapi.yaml` is the contract, generated from the FastAPI routes ([ADR 0006](../../adr/0006-code-first-openapi.md)); frontend types are generated from it (S-13).
- **Japanese UX rules** (F-01…F-53): 44 px tap targets, 確認画面 before Approve / Assign / Report, no AI buzzwords in copy.
- **Seed story:** fictional 「佐世保鋼材加工（架空）」. Machines: プラズマ切断機 #1, プレスブレーキ #2, 天井クレーン（玉掛け）#3, 溶接ブース #4. Foreman: 山口 隆 (veteran). Workers: Rahim Uddin, Sadia Akter, Tanvir Hasan (Bangladeshi), 田中 健 (Japanese). ~15 Glossary Terms (玉掛け, 段取り, 寸法, バリ, 保護メガネ, 非常停止, 可燃ごみ, 指定袋, 避難所…). Life: fictional 「みなと町自治会（架空）」 + a city account; Senpai pairs: Rahim ↔ 田中 健 (coworker), Sadia ↔ 自治会 volunteer 森 早苗. Notices: garbage rules (from a real public 佐世保市 garbage flyer photo, rules copied exactly), a 防災訓練 date, an autumn festival, a 自治会 clean-up duty.

## AI pipeline (`backend/app/ai/`, prompts in `backend/app/prompts/`)

One Gemini call per note, structured JSON output (response schema), audio as inline data:

1. Input: audio (webm/opus from `MediaRecorder`) or typed Japanese, plus the Glossary Terms list and the Icon id list.
2. Output JSON: `transcript_ja`, `easy_ja` (やさしい日本語, short sentences, steps numbered), `bn`, `en`, `back_bn_ja`, `back_en_ja`, `icons` (ids from the fixed set, ≤1 per step), `questions` (2–3, each with `term_id`, prompt and 3 options in ja/bn/en, `correct_index`).
3. Validate in code: JSON schema, icon ids exist, glossary lock (see constraints), exactly one correct option, 2–3 questions. Fail → retry once with the error appended → still failing → return draft flagged `needs_edit`.
4. Cache by `sha256(audio bytes + prompt version)` in `ai_cache`. Seed the cache with the filmed demo take.
5. Same pipeline (1 question) for Briefings; Near-miss Reports use a translate-only prompt (BN/EN audio → `text_ja`).
6. **Notices:** input is text, audio or a flyer photo (image inline). Output adds `source_ja` (OCR / transcript), `category`, `steps` (each ≤1 short sentence, e.g. 「可燃ごみ：月・木 8:00まで、市の指定袋」), and `events` (`title`, `rrule` or `starts_at`). Validate: every RRULE parses, every date is in the future, steps ≤8. The poster sees the source flyer next to the steps before publishing.
7. **Asks:** retrieval is plain: published Notices are few, so send all their `easy_ja` + `steps` (cap 30 newest, shortcut: no vector search; add pgvector when a district has >30 Notices) with the question. Output schema: `{answer_ja, answer_bn, answer_en, source_notice_ids, covered: bool}`. Reject `covered=true` with empty `source_notice_ids`. Senpai replies use translate-only.
8. Seed `ai_cache` with the filmed garbage-flyer photo so the opening hook is instant.

Icon set: ~30 SVGs from an open-licence pictogram set (record the licence in `frontend/src/ui/v1/icons/LICENSE`), ids like `ppe-goggles`, `hot-surface`, `lockout`, `measure`, `crane-sling`, `emergency-stop`.

## 3-minute demo script

0. **0:00–0:30 hook.** Hold up a real 佐世保市 garbage flyer. Community Poster snaps it; seconds later Rahim's phone reads, in Bengali, "Burnable: Mon/Thu before 8:00, city's designated bag", with "Add to calendar" tapped and tomorrow's reminder shown. Rahim asks by voice "what about the broken fan?"; the answer quotes the 粗大ごみ line of the same Notice. Cut to: "That's home. Work is harder."
1. **0:30–2:20 core.** A Worker nods 「わかりました」. Caption: MHLW 46.2% (exact wording above).
2. Foreman scans the QR on プラズマ切断機 #1 and records 20 s in Japanese.
3. Draft shows やさしい日本語 + Bengali + English + back-translation + icons; Foreman approves. Machine Panel beside it turns red for everyone: new version, old Sign-offs expired.
4. Rahim scans the same QR, answers in Bengali, gets one wrong. Panel stays LOCKED.
5. Foreman board turns red: "Rahim — 寸法 (measurement)". Foreman re-explains; Rahim passes; Panel turns green.
6. **2:20–3:00 breadth.** Quick cuts: board flags an assigned Worker without a Sign-off; Skill Matrix with amber cells; Confusion Heatmap; a Near-miss Report arriving in Japanese; Rahim and his Senpai 田中 logging a 防災訓練 Meet-up; Support Log CSV opening in Excel.
7. Close: "Understood at work. Understood at home." (Rahim's Skill Passport next to his Life calendar.)

## Review focus

1. **Glossary lock bypass:** AI output drops or re-translates a locked term. Test: validator rejects it.
2. **Stale Sign-off:** a Worker passes v1, Foreman approves v2, Panel must show LOCK. Test in WS2.
3. **Answer leak:** `GET /machines/{id}` must not return `correct_index`. Test it.
4. **Demo without network:** every journey passes with `USE_MOCK=true`.
5. **Accounts:** every protected endpoint returns 401 without a token; a Worker or Community Poster token gets 403 on Foreman endpoints; an id from another shop returns 404 (guard test, BACKEND_ARCHITECTURE.md §3.3).
6. **Invented rule:** an Ask the Notices don't cover must return `covered=false`, never a guessed answer.
7. **Wrong garbage day:** an Event can't publish unconfirmed; RRULE expansion test in WS10.
8. **Senpai link leak:** `/senpai/$token` shows only that pair's Worker; a wrong token returns 404.
