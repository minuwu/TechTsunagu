# The Lock is software; the interlock is simulated

A Machine is "locked" for a Worker only in software: the Machine Panel page shows Lock until that Worker has a valid Sign-off, and the Foreman board shows the same state. No PLC, relay or CAD/CAM (ANS WIN) integration is built. A real interlock is pitched as future work. This keeps the build to 3 days and avoids any claim that the app makes a machine physically safe.
