# The Android app ships Japanese and English only

Decided 2026-11-24 by Minhaz. The Android app's UI and content language is Japanese or English; Bengali (`values-bn`, the `bn` locale and the Bengali options in the Me and Onboarding pickers) is removed. A Worker whose server profile language is anything other than `ja` (for example `bn`) reads the app in English: `appLanguage()` in `:core:model` maps the profile language once, at sign-in (`UserDto.toUser()`), so every screen keeps reading `session.user.language`. The backend and web app are unchanged and still store and translate other languages. Consequences: this supersedes the Bengali part of ANDROID_ARCHITECTURE D-08 (no Bengali font subset is needed); Tri maps may still carry a `bn` key from the server, which the app ignores; adding a language back means restoring its `values-*` folder, its `locales_config.xml` entry, the picker options and the `appLanguage()` rule.
