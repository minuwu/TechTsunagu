# One AI seam with a Gemini adapter and a fake adapter

All model calls go through `AiClient` in `backend/app/ai/client.py`, which has two adapters: `GeminiClient` and `FakeAiClient`. The fake returns recorded fixture JSON and is the default (`AI_MODE=fake`) for tests and day-to-day development, because Gemini's free-tier daily request limit is small and not reliably published, and five developers testing against it would use it up before the demo. Services never call Gemini directly; they call pipelines (`build_note`, `build_notice`, `answer_ask`, `translate`) that own the cache, validation, the single retry and the fallback to seeded results, so a slow, rate-limited or malformed response degrades to a `needs_edit` draft instead of an error. The real adapter is switched on with `AI_MODE=gemini` for prompt work, the filmed takes and the live demo, and its results are cached in `ai_cache` so the same input never spends quota twice.
