# The Brand kit: Nekko, two blues, vector only, and two departures from ADR 0012

The Brand kit (app icons, favicons, Lottie, website images; spec in [docs/brand/SPEC.md](../brand/SPEC.md)) is built from one traced master of the mascot Nekko, so every asset shares one drawing. It ships in two blues: Site cobalt `#1351AA` (the v4 colour) as primary, and the original icon's `#246DD4` as an alternate generated by script, so the two sets cannot drift. Everything is vector (SVG and Lottie JSON, with PNG/WebP exports) because no image-generation model was available; a prompt pack covers external generators. Website images follow a Mixed style: hero, footer and social images stay Poster Modernist (cream, jet, cobalt, 0 px corners), while app icons, spot illustrations, empty states and Lottie use rounded, playful shapes. That is a deliberate departure from ADR 0012's "all other art is cream, black and cobalt, 0 px" and from its single blue, taken because a friendly mascot and a second blue were the brief. The assets live in `frontend/public/brand/` and are not wired into `frontend/src` yet; teammates wire favicon links and a Lottie player from [docs/brand/README.md](../brand/README.md).
