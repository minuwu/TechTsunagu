# Surface: Wakatta? app, UI kit v2

Scope: every screen of the v2 kit (frontend/src/ui/v2). Mode: Operate. Users: Workers on phones (shop floor, home), Foremen on PCs, Machine Panel tablet, Japanese judges watching the whole flow. Code-led; no image generation. Replaces the earlier industrial-signage world (user decision 2026-11-22).

## Direction contract

THESIS: Wakatta? feels like a trustworthy Nagasaki public service: harbour navy and porcelain white, calm and precise, so a foreign worker and a Japanese foreman both trust what it says. It refuses the generic SaaS default (grey cards, one blue accent, scattered gradients) and any tourist-kitsch motif.

OWN-WORLD: deep harbour-navy header; warm porcelain-white ground; white panels with a hairline and a soft offset shadow; ocean blue for actions; a subtle teal for the Life side; red / green / amber only for Lock / Ready / expiring. Noto Sans JP throughout (F-09), refined by scale, weight and palt. Line work in the indigo of Hasami / Mikawachi blue-and-white porcelain; drawn SVG icons in one stroke.

STORY: a judge sees whom it serves in one line, opens a Worker, scans a Machine, follows the 1 Read, 2 Check, 3 Done steps, watches the Panel turn from Lock to Ready, then reads the Foreman's board.

FIRST VIEWPORT: navy header (bridge-arc mark, name, tagline, language switch). Page head: h1, one line of what and for whom, how to use the demo. Role panels: Workers first (primary path), Machines with Scan / Panel, Foreman, Community, Senpai; Reset below.

SIGNATURE MOVE: the Megane-bridge arc. The mark is an arch and its reflection closing into a circle. The same arc rises on the Lock-to-Ready state plate and is the brand splash on first load; an indigo harbour hairline closes the header.

FORM: Nagasaki public service, seed: none (pinned) "Premium Japanese-inspired design: deep navy, ocean blue, subtle teal, warm white, refined typography, minimal aesthetic. Use subtle Nagasaki-inspired visual elements without sacrificing usability or looking gimmicky."

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
